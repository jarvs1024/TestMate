# TestMate 术语与文案规范

> 适用范围：前端用户可见文案、后端返回给用户的报错、内置连接说明、README 与设计文档。
> 代码注释与历史文档里的旧叫法可以保留，但必须能看出是历史；**用户能看到的字一律以本表为准**。

## 一、核心术语

| 概念 | 统一叫法 | 可用解释/别名 | 禁止在用户界面使用 | 说明 |
|---|---|---|---|---|
| 首页能力总览 | **能力墙** | 工作台 | 智能体广场、广场 | 首页 `/`；一张卡 = 一项能力 |
| 能力角色 | **资产 / 工具 / 看板** | 供料 / 干活 / 看数 | 底座 | 角色只回答「这卡干嘛」 |
| 扩展存放与浏览页 | **扩展库** | 扩展资产 | 插件·技能·连接、扩展市场、AI 资产市场 | `/extensions`；2026-11-04 定名 |
| 扩展库里的三类内容 | **插件 / 技能 / 连接器** | 扩展 | 资产（单独使用，易与角色名混淆） | 连接器 = MCP 配置型资产 |
| 平台自带的 MCP 连接 | **内置连接器** | — | 内置资产（内部代码可叫，界面不用） | 如扩展库助手、知识库助手 |
| 个人令牌 | **访问令牌** | API Token（仅配置占位符） | Token（裸用） | 个人中心「访问令牌」新建/删除 |
| MCP 客户端授权 | **授权管理** | MCP 授权 | 连接管理 | 个人中心「授权管理」可撤销 |
| 外部系统账号绑定 | **平台认证** | 外部平台认证 | 数据源、集成账号 | PingCode / PLM 等账号在这里配置 |
| 知识库的 RAGFlow 空间 | **用户空间** | RAGFlow 空间 | 知识库空间、多用户空间 | 一把 API Key = 一个用户空间 |
| RAGFlow 数据集 | **数据集** | 知识库数据集 | 库（单独使用） | 数据集下含文档、分段 |
| RAGFlow 文档切分结果 | **分段** | chunk | 片段（与「文档」混用） | — |
| 代码评审看板 | **代码检视** | 代码检视看板 | 代码审查（页面名） | 后端服务名 ReviewAgent 保留英文 |
| 外部 AI 客户端 | **Agent** | 智能体（仅历史解释） | 智能体（作为当前功能名） | 例：「挑一个装进你的 Agent」 |
| 模型计量单位 | **Token** | 模型 Token | 令牌（指模型计量时） | 与「访问令牌」严格区分 |

## 二、文案规则

1. **用户可见文字用中文**；产品名、协议名、字段名、命令、配置键保留英文，例如 `space_id`、`scope`、`MCP`、`ReviewAgent`。
2. **标点**：中文句子用全角标点（，。；：「」）；代码、命令、配置值周围用反引号或半角括号。
3. **报错必须自解释**：
   - 不用 `admin only`、`not found`、`invalid` 这类英文结论；
   - 校验失败要说清**字段中文名 + 当前值 + 合法取值**，例如「业务域『foo』不存在；可用值：auto-code, ssd-ops」；
   - 保留 HTTP 状态码语义，不改变状态码。
4. **动作词跟页面名一致**：扩展库用「上架 / 下架 / 发新版本」；软件库用「上传 / 发布新版本 / 下架」；知识库用「上传 / 更新 / 重新解析 / 删除」。
5. **导航路径写全**：涉及个人中心时写「个人中心 → 访问令牌」或「个人中心 → 平台认证」，不写「授权管理 → 新建令牌」。
6. **配置占位符例外**：内置连接配置里的 `<你的API Token>` 是生成出来的配置字面量，保持原样；正文说明一律叫「访问令牌」。

## 三、代码注释与文档

1. 注释写**为什么**，不重复代码在做什么；历史决策可标日期，但过期结论要加「已过期 / 已被取代」并指向现行文档。
2. 引用文件路径必须真实存在；文件移动后同步更新引用。
3. 设计文档开头统一写：日期、状态（讨论中 / 已确认 / 已实现 / 已被取代）、涉及模块。
4. 被后续决策推翻的文档，在标题下加「⚠️ 已被取代」横幅，不删除原文。
5. MCP 协议层的兜底错误（`SafeError` 的通用文案）保持英文，避免把内部细节回给 Agent；业务校验错误仍用中文。

## 四、现行口径速查

- 页面：能力墙 / 扩展库 / 知识库 / 软件库 / 代码检视 / 个人中心 / 设置
- 角色：资产 / 工具 / 看板
- 个人中心页签：授权管理 / 访问令牌 / 平台认证
- 设置页：能力墙 → 资产 → 扩展库 / 知识库 / 软件库；看板 → 代码检视
